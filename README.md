
# **GIBAGym – Intelligentes Biofeedback-System für den Kraftsport**

Dieses Repository dient als zentrale Entwicklungsplattform für das Diplomarbeitsprojekt **GIBAGym**. Ziel des Projekts ist die Entwicklung eines innovativen, kostengünstigen Wearables zur Echtzeit-Analyse von Muskelaktivitäten mittels Elektromyografie (EMG) und künstlicher Intelligenz, kombiniert mit einer plattformübergreifenden App.

Das Gesamtsystem basiert auf einer modernen Multiplattform-Architektur, um eine native und performante Ausführung sowohl auf **iOS** als auch auf **Android** zu garantieren. 

**Aktueller Projektstatus:**
Das Repository befindet sich derzeit in der initialen Planungsphase. Aktuell werden hier vorübergehend visuelle Ressourcen, Logos, Design-Assets und Architekturentwürfe gesammelt, bevor die aktive Programmierphase der App und der Firmware startet.
